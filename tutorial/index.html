GETTING STARTED

動画で見る基本操作

図形を描くところから、アニメーションを保存するところまで。
実際の操作画面で手順を確認できます。

字幕付き・音声なし。全画面にすると操作箇所を確認しやすくなります。動画を保存

操作の流れ

  1. 左のツールで図形を選び、キャンバスをドラッグして描きます。
  2. 「形を選択」で描いた形をクリックし、動きを付ける範囲を選びます。
  3. 右側で回転・移動・拡大・縮小を選び、方向や強さを設定します。
  4. 「ガイド」をオフにして「再生」を押し、見え方を確認します。
  5. 「書き出し」でGIFを選び、作成後の保存リンクからダウンロードします。APNGも同じ画面で選べます。

あとで編集を続ける場合は、「ファイル」→「プロジェクトを保存」からJSONも保存してください。
